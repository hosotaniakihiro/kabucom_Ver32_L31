# 家を見るAI — プライバシー

## 1. 表示しない情報

- **所有者氏名・所有者住所・電話番号などの個人情報は扱わない・表示しない。** 登記情報の取得機能も持たない。
- 所在地は **町丁レベル**（例: 「○○一丁目付近」）まで。番地・号は表示しない。
- 建物名は公開データ（PLATEAU / OSM）にある名称のみ。個人宅の表札情報は扱わない。
- 「所有者を調べる」機能は主要機能にしない（実装なし）。

## 2. 利用者の識別

- アカウント・ログインなし（現段階）。端末で生成した**匿名 UUID**（`X-IeMiru-Device`）で利用者データを分離する。
- 端末IDは氏名・メール・電話番号等と紐付けない。端末を変えると別人扱い（引き継ぎは将来の認証導入時に検討: HUMAN ACTION）。

## 3. 保存するデータ

| データ | 保存先 | 内容 | 誰が見られるか |
|---|---|---|---|
| 位置情報（候補検索） | **保存しない** | リクエスト処理中のみ使用 | — |
| 保存した家 | D1 `saved_buildings` | 建物ID・呼び名・状態・建物の重心座標・用途 | 本人の端末のみ |
| 修繕記録 | D1 `inspections` + R2 | カテゴリ・写真・マーク・メモ・サイズ | 本人の端末のみ（写真 URL は端末ID必須） |
| ARメモ | D1 `ar_notes` + R2 | 状態・メモ・アンカー（撮影時の位置・姿勢・ARWorldMap） | 本人の端末のみ |
| 建物分析キャッシュ | D1 `buildings` 等 | 公的データ由来の建物・査定・ハザード（個人情報なし） | API 経由で誰でも同じ結果 |

- ARメモのアンカーには**撮影時の緯度経度**が含まれる（自分で置いたメモの再表示に必要）。修繕写真には人物・車両ナンバー等が写り得るため、撮影時に注意を促す文言を追加すること（今後の改善）。
- 写真は EXIF を含まない形で縮小再エンコードしてから送信（Web: canvas 再エンコード、iOS: UIImage→JPEG）。

## 4. 外部への送信

- 不動産情報ライブラリ・国土地理院・PLATEAU 配信元へは**建物の重心座標／タイル座標・市区町村コード**のみを送る。利用者ID・端末IDは送らない。
- 不動産会社査定（`AppraisalProvider`）は既定で**未接続**。接続する場合も、連絡先は利用者が**明示同意**（`contact.consent === true`）した場合のみ渡す設計。

## 5. 権限

| 権限 | 用途 | 拒否時 |
|---|---|---|
| 位置情報（使用中のみ） | 建物候補の特定 | 地図での手動選択へ誘導（クラッシュしない） |
| カメラ | 「見る」・修繕写真 | 方位＋位置で候補提示 / 写真なしで記録可能 |
| モーション（方位） | カメラの向き | 手動方位スライダー / 地図選択 |

## 6. 削除

- 保存した家・修繕記録・ARメモは個別に削除可能（R2 の写真・ARWorldMap も同時に削除）。
- 端末単位の全削除 API・退会フローは未実装（HUMAN ACTION: 運用ポリシー決定後に実装）。
