## 1. PLATEAU

- **配信形式**: 3D Tiles / MVT / CityGML / GeoJSON など年度・都市で異なる。本実装は**ベクトルタイル（MVT, z16 既定）**を URL テンプレートで受ける（`PLATEAU_MVT_URL=https://.../{z}/{x}/{y}.pbf`）。どの配信 URL を使うか（公式配信・自前変換・CDN）は利用規約を確認のうえ人間が決める（HUMAN ACTION）。
- **属性の正規化**（`normalizePlateauAttributes`）: 名前空間・記号・大小文字を無視したキーで照合。`bldg:measuredHeight` / `measuredHeight` / `計測高さ` 等。
  - 用途 `bldg:usage` コード表（401〜461）、構造 `uro:buildingStructureType`（601〜612）を日本語化。
  - `-9999` 等の無効値・範囲外・「不明」は **null**。
- **地域差**: 高さ・階数・築年が無い都市は普通にある。UI は「データなし」と表示し、階数は高さから推定できる場合のみ **AI推定** バッジ付きで出す。
- タイル境界で分割された同一建物は面積最大の断片を採用。

## 2. 不動産情報ライブラリ（国土交通省）

- ベース URL: `https://www.reinfolib.mlit.go.jp/ex-api/external/{API}`。キーは **`Ocp-Apim-Subscription-Key` ヘッダ**で送り、URL・ログに載せない（`redact`）。キーは Cloudflare Secret / `.dev.vars` のみ。
- タイル系 API は `response_format=geojson&z&x&y`。用途地域・ハザードは z15、地価は z13（半径 2km をカバーするタイル）。
- 取引価格 XIT001 は `year`（直近2年）・`city`（逆ジオコーダの市区町村コード）で取得。
- **パーサは属性名の揺れに耐性**（`pickProp` で候補キーを順に探す）。ハザードの浸水深は属性名ではなく「〜m」という値の形でも拾う。属性名は API 仕様書と照合して調整が必要な可能性がある（ライブ未検証のため。HUMAN ACTION）。
- **モック**（`MockReinfolibClient`）: 本番と同じ JSON 形状を決定的に生成し、同じパーサ・画面を通す。出典 `mode: 'mock'` → UI に「モックデータ・実データではありません」。**実データと混同しない。**

## 3. ハザードの状態（「安全」を表示しない）

| 状態 | 表示 | 意味 |
|---|---|---|
| `in_zone` | 想定区域内（深さ/区分） | 地点を含む区域ポリゴンがある |
| `graded` | 液状化の発生傾向: ○○ | 段階評価データ |
| `no_data` | **データなし** | 区域の登録が見つからない（区域外とは限らない・安全ではない） |
| `not_applicable` | **対象外** | 海に面していない県の津波・高潮 |
| `unavailable` | **確認できず** | 取得失敗・未接続（内水） |

「安全」「区域外」の状態は型に存在しない。テストで全状態のラベルに「安全」が含まれないことを保証。

## 4. 推定値・ユーザー入力の扱い

| 種類 | バッジ | 例 |
|---|---|---|
| 公的データ | 公的データ | 用途地域、地価公示、取引事例、PLATEAU 属性 |
| 推定 | AI推定 | 参考査定、敷地・延床面積の推定、高さからの階数推定 |
| 利用者入力 | ユーザー登録 | 修繕記録、ARメモ、保存した家 |
| 参考 | 参考情報 | 周辺取引事例のまとめ（参考相場）、建て替えの建築費目安 |

## 5. 出典表記

各セクションに `出典: <ソース名>【モック/デモ表記】` を表示。出典は `SourceRef { id, name, url, license, mode, fetchedAt }` で API レスポンスにも含まれ、D1 の `building_sources` に保存される。

- 不動産情報ライブラリ: 「出典: 国土交通省 不動産情報ライブラリ」（加工して利用）

- OSM: 「© OpenStreetMap contributors (ODbL)」
