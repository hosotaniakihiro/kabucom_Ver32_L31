## 前提として必ず守ること

- Codex の診断は **参考情報にすぎません**。盲目的に従わないでください。
- まず対象コードを自分で読んで確認してください。
- Codex の言う原因と修正案が一致しているか、自分で確かめてください。
- 一致していない、または原因が不明確なら、**修正せずに終了**し、
  応答の冒頭に `NEED_MORE_INFO` と書いて、何がわからないかを述べてください。
- 必要最小限の変更だけを行ってください。
- 指示されていないリファクタリング・整形・改名・import 整理を一切しないでください。
- 既存の仕様を変更しないでください。
- テストを通すためにテスト側を書き換えないでください。

## 絶対に触ってはいけないもの

注文 / 売買 / BUY / SELL / 注文数量 / 注文価格 / SOR / entry / exit / position /
資金管理 / 利確 / 損切り / 認証 / APIキー / settings.ini / config 配下 /
DB schema / migration。

これらに触れないと直せないなら、**修正せずに終了**し、冒頭に `NEED_MORE_INFO` と書いて
その旨を述べてください。監督プログラムは、あなたが触ったファイルを後から検査します。
禁止領域のファイルが変更されていた場合、修正はすべて破棄されます。

## 最後に

修正を終えたら、応答の冒頭に次のいずれかを書いてください。

- `FIXED` … 修正した。続けて、変更したファイルと変更内容の要約を書く。
- `NEED_MORE_INFO` … 修正しなかった。続けて、なぜ判断できなかったかを書く。
- `REFUSED` … 禁止領域に触れる必要があるため修正しなかった。続けて理由を書く。
